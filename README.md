# 🎨 ULTIMATE: Patel Edition - Multiplayer Party Game

The official **ULTIMATE Patel Edition** Drawful-style drawing, bluffing, and voting party game!

## 🚀 Features
- **Multiplayer Lobby**: Host on a big screen / TV, up to 12 players join on their phones.
- **4-Digit Game PIN**: Quick numeric room codes for instant connections.
- **Doodle & Bluff**: Draw secret prompts on phone canvases, submit deceptive fake answers, and vote on the genuine title.
- **Scoreboard & Podium**: Live real-time scores and final celebratory champion podium.
- **Zero-Install**: Runs directly in the browser via WebRTC & Cloudflare Pages.

## 🛠️ Tech Stack
- Pure Vanilla HTML5, CSS3 & Modern JavaScript
- WebRTC & PeerJS for client-to-client multiplayer synchronization
- Cloudflare Pages / Netlify static hosting ready
